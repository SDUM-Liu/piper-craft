# 实机经验与验证边界

以下为同一现场的交互控制摘要。原始RGB、SDK轨迹和录像不随开源代码发布；失败/中止材料在完成复核与知识提炼后按本机留存规则删除，成功/未知任务及用户保留的人类示范分别管理。仓库保留此前公开的压缩Demo，读者无法仅凭这些片段独立复验实体任务。

## 辅助腕相机与倒水

首轮倒水有水入杯，用户确认桌面有少量水。重试先调整左腕相机作为固定侧视，再切右臂抓瓶；顶视看平面位置、持物腕看夹持、另一腕看瓶口与杯沿间隙和水流。左腕实际拍到水流进入杯内，用户当次确认没有新增洒水。仅一次成功任务，没有量化多视角带来的提速或成功率提升。

可复用步骤：低位试提和短移后再搬运；未出水时交叉观察并对位；接近出水每次小角度观察；见水入杯后反向断流，在杯上观察残滴后再撤；近桌分步下降、分步开爪，短退确认瓶子独立稳定。实际倾角、路径和按键时长取决于现场，不能重放本次时序作为通用动作。

顶视投影重合不能证明瓶口在杯上；恢复旧SDK姿态不能证明瓶体回正。影像近桌不等于测得承托力。本次松爪时有轻微姿态调整，不能声称零位移轻放或通用零洒漏。

## 尚未解决的边界

- 长按Q可以持续请求闭合，但释放其他运动键仍会触发pause/freeze，以实读开度保位，静止后Q才恢复。预紧保持问题未修复；SDK effort不是标定后的指端力。
- 未整瓶滑落不能证明无微小滑移或转动；本次没有测量倒水体积或接触力。
- 本地控制不检查入口、路径及夹爪包络自碰撞，也没有桌面、物体或跨臂环境防碰撞；原生MOVE_P已禁用，不代表控制器具有等效检测。
- 近基座/奇异姿态可能缩步或受阻，后台绕行中TCP可能有明显偏移；不要在瓶杯附近假设TCP沿直线运行。
- 恢复入口曾因使能后反馈变化拒绝；稳定后重入成功。恢复取消部分本地检查/预算后的有限实机记录，不代表两轮冷启动或全部起姿验收。
- J1–J6按钮只完成双臂部分轴/方向的实机动作观察，不代表所有按钮、档位及输入取消事件全面验收。
- 曾出现连续计算截止时间超限并停止，原因尚未完全排除。离线回归通过不代表实机动作性能或任务成功。
