# 实体任务的局部动作规划

## 桌面夹取：按阶段核查（10-30用户要求）

1. 先确定辅助臂位姿：顶视核对双臂、线缆及将要接近/旋转/试提的空间；辅助腕在保持双臂/桌面间隙、避开遮挡的前提下尽可能低位侧看，实际辨认指尖、目标和桌面的高度及入夹关系。必要时先按普通真机流程分步调整辅助腕位置和朝向，再让它保持观察；不能将辅助腕也调成朝下俯视来代替高度判断。低位侧视不等于仰视，暂不引入仰视。11-03用户指出辅助视角过近：低位不要求贴近拍特写，优先让画面同时容纳两片指垫、球头和周围桌面；过近裁切、遮挡或侵入操作空间时退开辅助腕。
2. 仅抓取臂进夹要求垂直向下：在有间隙高度把抓取臂TCP工具+Z调为垂直桌面向下，张爪接近目标上方；辅助腕保持低位侧视。用SDK方向和源RGB交叉核对，基座Z、单个RPY值不能代替工具Z。
3. 基坐标小步靠近桌面（Shift −Z、Space +Z退离）；辅助腕确认指尖、目标与桌面高度，顶视/操作腕确认平面位置。看不清先补观察，不下降猜接触。
4. 闭爪前明确进夹方向、双指闭合方向相对物体轴线的关系、抓取部位/位置/高度及后续退出空间。羽毛球区分球头与羽毛，优先核查球头可夹区；球筒区分筒身与筒沿。
5. 用户建议基坐标O/P调整，须按当前真实轴义执行：O/P绕∓X倾斜，J/L绕±Z。桌面内改变闭合朝向不能把O/P当成绕桌面法线；在有旋转间隙处调整，随后重查工具Z向下和抓点，不暗改按键映射。
6. 结合辅助腕继续小步下降，使目标进入双指内部；核查入夹程度、两侧闭合接触路径、夹持高度与指尖间隙。避免指尖浅夹，不盲推到底；辅助视角被遮挡就先解决遮挡。
7. 上述关系已看清才分步闭爪、低位短提；检查实际离桌及相对滑移/转动。未带起或滑转回到方向/抓点/接触/夹深复核，不连续收爪试提。

`planning-context`固定返回结构化`desktop_grasp_guide`及`problem_lessons`，即使没有成功地图也可用。执行前用`grasp-review --stage 阶段 --review 观察JSON`列出未满足项；这是Codex填写观察的完整性检查，不是控制器拦截或自动识图。每轮仍只规划1–3个局部动作，按新现场更新。

10-30用户明确：安全、可恢复的放置允许有位置不确定性，不得因不能保证准确而拒绝尝试；羽毛球掉落可重新捡取。记录本次预期放置位置与实际落点，根据结果调整下一次；区分准确性未知与危险，保留新鲜观察、双臂/桌面间隙、反馈和停止守护。尝试不冒充成功，释放后按实际结果核查。
10-28用户明确：自动绕行属于正常操作；不能仅因触发、规划或执行绕行就视为异常或主动取消。结合当次物体抓持、桌面/双臂间隙和新鲜RGB/SDK反馈继续观察执行；实际异常、反馈过期、停止请求等既有守护仍保留。
先明确最终完成条件，再规划接下来1–3个局部动作；每段执行后，按真实结果更新下一组。示范仅提供方法参考，不重放坐标、关节或按键。先用常识核对：羽毛球球头先入筒；开口与封底、物体重心和承托、抓持与插入方向、夹爪退出空间、释放顺序。看不清就补观察，不用连续试键代替判断。

10-28用户明确：任务相关操作不得向用户提问或请求确认；信息不清由Codex主动读取顶视和双腕源帧、必要时按普通真机流程调整辅助腕视角及检查新鲜反馈来核实，自主更新局部动作。不能把未知当事实；关键关系仍不清时停止相关动作并继续可行的观察/诊断，不用询问替代现场核查。

10-28用户指出反复桌面截图造成屏幕闪烁：禁止在点击/按键脚本中自动截屏；物体和空间判断只读三路相机源PNG及新鲜SDK反馈，界面状态优先用RPC/窗口属性读取。整窗录像读取PIPER CRAFT自身渲染帧，不调用系统截屏。

10-29用户要求：已有真实成功案例时，第二次必须以比第一次更快完成为目标。先评估案例与当前任务范围、物体、起姿和完成判据是否相符，明确复用哪些分工、抓点、朝向、观察位置及阶段策略，删去重复摸索和无必要等待；不重放旧按键/坐标，不省必要现场复核。按一致的任务范围、起止点与完成判据记录实际用时及提速是否达成；历史无可比计时就明确未知、建立基线，不能把历史部分成功当作完整任务的计时基准。

| 项目 | 需要明确的事实 |
|---|---|
| 目标与前置条件 | 本步要改变什么，前一步完成了吗，物体是否被可靠抓持/承托 |
| 控制 | 哪只臂、基坐标或运动坐标、具体轴与正负方向；不能按图像左右猜按键 |
| 细节 | 进夹方向及双指闭合方向相对物体轴线的关系；具体抓取部位、位置/高度、双指进入程度、两侧接触、指尖/筒沿间隙、另一臂空间；抓点须兼顾后续操作和撤爪 |
| 观察 | 直接读顶视与双腕源PNG，记录每路看清什么、遮挡什么及源时间戳 |
| 完成判据 | 真实离桌无相对滑移、球头已进入筒口、松爪后独立稳定等可见结果 |
| 异常处理 | 接触不明、滑移、姿态偏转或反馈异常时停止；复核后选退离或补观察 |

抓取前先核查夹爪朝向、夹取位置和夹深；羽毛球区分球头与羽毛，球筒区分筒身与筒沿，不以画面居中代替抓点和接触核查。短提/短移后复核，未带起或滑转时回到方向、抓点、接触与夹深判断，不能盲目继续收爪、下降或反复试提。插入/倾倒前重新核对方向与高度，释放前确认当次承托，释放后检查独立稳定。开度、effort、SDK到位或投影重合都不能替代这些事实。无标定不报实物毫米距离。

图像使用 `python -m astra_vla.observe --output /tmp/piper_observation`。该只读命令从现有采集worker获取三路无损PNG，不发送机器人指令，不独占或重新打开相机。它保留采集流分辨率，不通过屏幕截图读取物体，不把放大解释为新增细节。桌面截图仅用于界面检查。

真机维护验收也先列局部动作：观察与启动核查 → 小幅平移及松键静止 → 小幅旋转及松键静止 → 切模式清输入/确认停止 → 另一模式重复核查 → F9停止。逐段比较SDK实读方向和实际影像，禁止把离线结果写成实机验收。
