# 实体任务的局部动作规划

先明确最终完成条件，再规划接下来1–3个局部动作；每段执行后，按真实结果更新下一组。示范仅提供方法参考，不重放坐标、关节或按键。先用常识核对：羽毛球球头先入筒；开口与封底、物体重心和承托、抓持与插入方向、夹爪退出空间、释放顺序。看不清就补观察，不用连续试键代替判断。

每步明确以下信息：

| 项目 | 需要明确的事实 |
|---|---|
| 目标与前置条件 | 本步要改变什么，前一步完成了吗，物体是否被可靠抓持/承托 |
| 控制 | 哪只臂、基坐标或运动坐标、具体轴与正负方向；不能按图像左右猜按键 |
| 细节 | 双指进入程度、两侧接触、夹持高度、指尖/筒沿间隙、物体轴线、另一臂空间 |
| 观察 | 直接读顶视与双腕源PNG，记录每路看清什么、遮挡什么及源时间戳 |
| 完成判据 | 真实离桌无相对滑移、球头已进入筒口、松爪后独立稳定等可见结果 |
| 异常处理 | 接触不明、滑移、姿态偏转或反馈异常时停止；复核后选退离或补观察 |

抓取前先核查夹深，短提/短移后复核，插入/倾倒前重新核对方向与高度，释放前确认当次承托，释放后检查独立稳定。开度、effort、SDK到位或投影重合都不能替代这些事实。无标定不报实物毫米距离。

图像使用 `python -m astra_vla.observe --output /tmp/piper_observation`。该只读命令从现有采集worker获取三路无损PNG，不发送机器人指令，不独占或重新打开相机。它保留采集流分辨率，不通过屏幕截图读取物体，不把放大解释为新增细节。桌面截图仅用于界面检查。

真机维护验收也先列局部动作：观察与启动核查 → 小幅平移及松键静止 → 小幅旋转及松键静止 → 切模式清输入/确认停止 → 另一模式重复核查 → F9停止。逐段比较SDK实读方向和实际影像，禁止把离线结果写成实机验收。
